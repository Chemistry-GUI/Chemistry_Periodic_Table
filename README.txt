# ElementX — Interactive Periodic Table

Files:
- index.html
- style.css
- script.js

Features:
- All 118 elements in a standard 18-column periodic-table layout
- Click any element to open a detailed information panel
- Search by element name, symbol, or atomic number
- Category filter
- Dark/light theme
- Responsive layout
- Basic element data works without an API
- Extended properties are loaded from the Periodic Bubbles element API when a card is opened

For GitHub Pages:
1. Upload the three files to a repository.
2. Keep index.html at the repository root.
3. Settings -> Pages -> Deploy from branch -> main -> /root.
